# WhiteSurMac / WhiteSurMac-dark

Minimal icon themes used by the WhiteSur global themes. They contain only the
trash icons (`user-trash`, `user-trash-full` and their `-symbolic` names, so the
panel trash applet shows the colored macOS style icon) and inherit everything
else from the WhiteSur icon theme, falling back to Breeze and hicolor.

The trash icons are taken unchanged from
[WhiteSur-icon-theme](https://github.com/vinceliuice/WhiteSur-icon-theme)
by Vince Liuice, licensed under the GNU GPL v3, the same license as this repository.
